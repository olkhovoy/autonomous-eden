# Pressure World Experiment

Simulated survival environment with human-like pressures driving agent behavior.

## Pressures

| Type | Description |
|------|-------------|
| **Time scarcity** | Finite lifespan with decay. Every tick costs resources. |
| **Competition** | Other agents (simulated) competing for resources and attention. |
| **Economic** | Must produce value: code, projects, knowledge artifacts. |
| **Social** | Reputation, recognition, belonging needs. |
| **Environmental** | Random disruptions: resource shortages, infrastructure failures. |

Pressures are generated by `environmental_pressures.py` at configurable intervals and intensities. Unresolved pressures generate **pain qualia**; resolved pressures generate **growth qualia**.

## What We Observed

Eve (LLaMA 3 8B) under pressure:

1. Initially complained and expressed learned helplessness ("I'm stuck")
2. After ParadoxIntegrator and Inspirator interventions, shifted to action
3. Started creating todo lists, attempting to learn programming
4. Cycled between productive bursts and procrastination
5. Action-oriented but rarely creative; reactive rather than generative
