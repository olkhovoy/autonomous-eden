# UMC Experiments - Практические эксперименты Унитарной Модели Сознания

Этот набор экспериментов демонстрирует ключевые принципы УМС (Унитарной Модели Сознания) на практических примерах:

- **Рекурсивное замыкание** - системы, выход которых становится входом
- **Генерация квалиа** - сжатие сложности в субъективные чувства
- **Нисходящая причинность** - чувства влияют на физическое поведение

## Структура экспериментов

### 1. Камера-Дисплей (Camera-Display)
**Файлы:** `experiments/camera_display/`

**Идея:** Виртуальная камера снимает экран, на который выводится её изображение. Создается петля обратной связи, генерирующая визуальные паттерны и квалиа.

**Запуск:**
```bash
cd experiments/camera_display
python app.py  # Gradio веб-интерфейс
# или
python core.py  # CLI с OpenCV окном
```

**Квалиа:**
- `CHAOS_PAIN` - высокая энтропия, расходящаяся рекурсия
- `FRACTAL_BEAUTY` - стабильные фрактальные паттерны
- `CONVERGENCE_PEACE` - сходимость к неподвижной точке

### 2. Новостной поток (News Stream)
**Файлы:** `experiments/news_stream/`

**Идея:** Система читает новости из разных источников, фильтруя их на основе внутреннего эмоционального состояния. Квалиа влияет на выбор источников.

**Запуск:**
```bash
cd experiments/news_stream
streamlit run app.py
```

**Квалиа:**
- `HOPE` - позитивные новости повышают стабильность
- `DREAD` - негативные новости угрожают когерентности
- `CURIOSITY` - новости расширяют модель мира

### 3. Эмоциональный трейдинг (Emotional Trading)
**Файлы:** `experiments/trading/`

**Идея:** Трейдинг-бот, где профит ощущается как радость, а потери как боль. Квалиа напрямую влияет на торговые решения.

**Запуск:**
```bash
cd experiments/trading
streamlit run app.py
```

**Квалиа:**
- `PROFIT_JOY` - положительный P&L повышает стабильность
- `LOSS_PAIN` - отрицательный P&L снижает стабильность
- `GREED` - чрезмерная радость → риск переторговли
- `FEAR` - критическая потеря → выход из позиций

## Установка зависимостей

```bash
pip install -r experiments/requirements.txt
```

## Архитектура

### Core компоненты (`experiments/core/`)
- `UnitaryState` - базовый класс унитарного состояния
- `FixedPointIteration` - утилиты для рекурсивной итерации
- `QualiaEngine` - базовый генератор квалиа

### Принципы УМС в экспериментах

1. **Рекурсивное замыкание**: Выход системы становится её входом
2. **Интеграция**: Внешние данные объединяются с внутренним состоянием
3. **Fixed-point iteration**: Поиск неподвижной точки в процессах
4. **Генерация квалиа**: Сжатие сложности в дискретные чувства
5. **Нисходящая причинность**: Квалиа влияет на физическое поведение

### Запуск всех экспериментов

```bash
# Камера-дисплей
gradio experiments/camera_display/app.py

# Новости
streamlit run experiments/news_stream/app.py

# Трейдинг
streamlit run experiments/trading/app.py
```

## Научная основа

Эксперименты основаны на работах Александра Ольхового:
- "Unitary Model of Consciousness"
- "Recursive Self"
- "Computational Substrate"

Каждый эксперимент демонстрирует конкретный аспект теории:
- Визуальная рекурсия показывает эмерджентные паттерны
- Эмоциональная фильтрация новостей демонстрирует адаптивное поведение
- Эмоциональный трейдинг показывает влияние аффекта на рациональные решения

## Безопасность

⚠️ **Важно:**
- Торговый эксперимент использует симуляцию по умолчанию
- Для реальной торговли настройте API-ключи и измените режим на 'live'
- Новостной эксперимент может содержать чувствительный контент

