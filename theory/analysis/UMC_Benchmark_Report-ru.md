## 4. Ключевые Технические Инновации

### 4.1 Неявное Дифференцирование

Рекурсивная модель использует неявное дифференцирование для эффективного по памяти обучения:

```python
# Прямой проход: Итерировать до неподвижной точки
z* = fixed_point(f, z_0)  # z* = f(z*)

# Обратный проход: Решить линейную систему
# (I - J^T) v = dL/dz*
# dL/dθ = v^T @ df/dθ
```

Это обеспечивает обратный проход с памятью O(1) независимо от количества итераций.

### 4.2 Ускорение Андерсона

Сходимость ускоряется с помощью смешивания Андерсона:

```python
z_next = (1 - β) * z_new + β * z_old
```

где β вычисляется из истории невязок для минимизации времени сходимости.

### 4.3 Спектральная Нормализация

Матрицы весов спектрально нормализованы для гарантии сходимости:

```python
W_normalized = W / σ_max(W)
```

Это гарантирует, что якобиан имеет спектральный радиус < 1.


### 9.1 Преимущества Обучения с Неподвижной Точкой

Из `UMC_Fixed_Point_Analysis.md`:

1. **Эффективность параметров:** Одни и те же веса кодируют поведение на всех глубинах

3. **Эффективность памяти:** Обратный проход O(1) с неявным дифференцированием

## 10. Ограничения и Риски

### 10.1 Известные Ограничения

1. **Сходимость не гарантирована:** Некоторые входы могут не сходиться
2. **Нестабильность обучения:** Неявное дифференцирование может быть численно нестабильным
3. **Накладные расходы итераций:** Каждая итерация имеет вычислительную стоимость

### 10.2 Реализованные Меры

1. **Ограничение итераций:** Максимум 24 итерации
2. **Спектральная нормализация:** Обеспечивает сжатие
3. **Ускорение Андерсона:** Ускоряет сходимость
4. **Обрезка градиента:** Предотвращает взрыв

### 10.3 Риски для Гипотезы

Утверждение о 10-кратной плотности может не воспроизвестись, если:
- Итерация неподвижной точки требует слишком много шагов
- Совместное использование весов ограничивает выразительность
- Неявное дифференцирование вносит ошибки
